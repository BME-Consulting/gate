## 2. ペイン分析（ユーザー報告）

### ペイン① 二重ログイン問題（Critical）

**症状**: ネイティブログイン → Keycloakの二重ログインが発生

**根本原因（推定）**:
1. `index.tsx`（ログイン画面）でOAuth認証を実施
2. しかし、認証タブ（auth.tsx）や他の画面でも再ログインが要求される可能性
3. またはOAuthフローが不完全で、毎回Keycloakログイン画面が表示される

**期待される動作**:
- 初回ログイン1回のみ（トークンが有効な間は再ログイン不要）
- トークンリフレッシュは自動（ユーザーに見えない）

**調査が必要な箇所**:
- `apps/mobile/src/services/auth.ts` - OAuth実装
- `apps/mobile/src/services/tokenManager.ts` - トークン管理
- `apps/mobile/src/app/(tabs)/auth.tsx` - 認証タブでのログイン処理

**優先度**: **Critical**（毎回の操作で発生するUXブロッカー）

---

### ペイン② QR/顔認証切り替えのUX問題（High）

**症状**: 切り替わるたびに画角が変更され、人間にストレスを与えている

**根本原因（推定）**:
- QRスキャンと顔認証でカメラの設定（解像度、フレーム、ズーム等）が異なる
- 切り替え時にカメラが再初期化される
- UIの再レンダリングにより、画角がリセットされる

**期待される動作**:
- 切り替え時に画角を維持
- スムーズなトランジション（ちらつきなし）
- カメラの再初期化を最小限に

**調査が必要な箇所**:
- `apps/mobile/src/app/(tabs)/auth.tsx` - QR/顔認証切り替え実装
- `apps/mobile/src/hooks/useFaceDetection.ts` - 顔検出フック
- react-native-vision-camera の設定

**優先度**: **High**（頻繁に使う機能で現場作業員のストレス）

---

### ペイン③ 現場切り替え機能未実装（High）

**症状**: 現場（プロジェクト）を切り替えることができない

**要件**:
- デモスクリプト（line 284）で「複数の現場で同じアプリを使える」と回答
- ユーザーが現場を切り替えて、現場ごとのルール・データを管理できる

**現状**:
- `app.config.js:193` に `defaultProjectId: "PRJ001"` がハードコード
- 設定画面にプロジェクト設定項目はあるが、**切り替えUI/機能がない**
- 認証タブで常に同じプロジェクトIDが使用される

**期待される機能**:
1. **プロジェクト一覧画面**（または設定画面内のセクション）
2. **プロジェクト選択UI**（ドロップダウン or リスト）
3. **現在のプロジェクト表示**（設定画面 or ヘッダー）
4. **プロジェクト切り替え時のデータ分離**（履歴・統計が現場ごとに表示）

**OAuth 2.0実装との連携**:
- トークンのクレームに `resource_access: { "mc-gate": { "roles": ["project:PRJ001", "project:PRJ002"] } }` を含める
- ユーザーがアクセス可能なプロジェクト一覧をKeycloakから取得
- プロジェクト切り替え時に権限チェック

**優先度**: **High**（デモスクリプトで言及済み、現場運用に必須）
