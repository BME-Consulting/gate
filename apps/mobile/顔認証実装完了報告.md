## 動作確認方法

### 事前準備

1. **Face APIサーバーを起動**
   ```bash
   cd /volume2/Project/MCD3/TUMON/mc-gate/apps/face-api
   npm run dev
   ```
   → `http://localhost:8100` で起動

2. **作業員を登録**（Face APIに）
   ```bash
   # 作業員マスタを追加
   curl -X POST http://localhost:8100/api/workers \
     -H "Content-Type: application/json" \
     -d '{"personId": "P001", "name": "山田太郎", "company": "株式会社ABC"}'

   # 顔画像を登録（実際の顔画像のBase64データが必要）
   curl -X POST http://localhost:8100/api/face/register \
     -H "Content-Type: application/json" \
     -d '{"personId": "P001", "imageData": "data:image/jpeg;base64,..."}'
   ```

### アプリでの確認手順

1. モバイルアプリを起動
   ```bash
   cd /volume2/Project/MCD3/TUMON/mc-gate/apps/mobile
   npm start
   ```

2. 「顔認証」タブをタップ

3. カメラ権限を許可（初回のみ）

4. 顔をガイドフレーム内に合わせる

5. 白い円形の撮影ボタンをタップ

6. 「認識中...」が表示される

7. 結果が表示される
   - **成功時**: 緑チェックマーク + 作業員情報
   - **失敗時**: 赤エラーアイコン + エラーメッセージ

## 注意点

### 現在の制限事項

1. **Face APIのURLがハードコード**
   - `http://localhost:8100/api/face/recognize`
   - 本番環境では環境変数で管理が必要

2. **オフライン時の動作**
   - 現在はオンライン環境でのみ動作
   - オフライン時のエラーハンドリングが必要

3. **撮影画像のプレビューなし**
   - 撮影後すぐにAPIに送信される
   - 撮影確認・再撮影機能がない

4. **エラーメッセージが英語**
   - Face APIが返すエラーは英語
   - 日本語化が望ましい

## トラブルシューティング

### Q: カメラが起動しない

**A**: カメラ権限を確認してください
1. アプリを完全に終了
2. デバイス設定 → アプリ → MC Gate → 権限 → カメラ
3. 権限を「許可」に設定
4. アプリを再起動

### Q: 「認識中...」で固まる

**A**: Face APIサーバーが起動しているか確認
```bash
# サーバー起動
cd /volume2/Project/MCD3/TUMON/mc-gate/apps/face-api
npm run dev

# サーバー確認
curl http://localhost:8100/api/workers
```

### Q: HTTP error! status: 500

**A**: Face APIのログを確認
- モデルファイルが配置されているか（`apps/face-api/models/`）
- 顔が明確に写っているか
- Face APIサーバーのコンソールログを確認
