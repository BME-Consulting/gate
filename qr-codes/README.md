# QRコードサンプル

このディレクトリには、MC-Gate モバイルアプリのテスト用QRコードサンプルが含まれています。

## 生成日時

2025-11-13

## M1フォーマット（完全データ）

M1フォーマットは、以下の情報をパイプ区切りで含みます：
```
M1|personId|name|company|ccusId|socialInsurance|residencyExpiry|age|isSoleProprietor
```

### P001_m1.png - 完全データ（すべてのチェックをパス）
- **内容**: `M1|P001|山田太郎|株式会社ABC|C12345|1||35|0`
- **説明**: すべてのチェック項目をパスする理想的なデータ
- **特徴**:
  - CCUS登録済み (C12345)
  - 社会保険加入済み (1)
  - 日本人労働者（在留期限なし）
  - 一人親方ではない (0)

### P002_m1.png - CCUS未登録
- **内容**: `M1|P002|佐藤次郎|株式会社DEF||1||42|0`
- **説明**: CCUS未登録のケース
- **特徴**:
  - CCUS未登録（空文字）
  - 社会保険加入済み (1)
  - 警告メッセージが表示される

### P003_m1.png - 外国人労働者
- **内容**: `M1|P003|John Smith|株式会社GHI|C67890|1|2025-12-31|28|0`
- **説明**: 外国人労働者（在留期限あり）
- **特徴**:
  - CCUS登録済み (C67890)
  - 在留期限: 2025-12-31
  - 在留期限が近づくと警告が表示される

### P004_m1.png - 一人親方
- **内容**: `M1|P004|鈴木三郎|鈴木工務店|C11111|0||55|1`
- **説明**: 一人親方のケース
- **特徴**:
  - CCUS登録済み (C11111)
  - 社会保険未加入 (0)
  - 一人親方フラグ (1)
  - 一人親方は社会保険未加入でも警告なし

### P005_m1.png - CCUS未登録 + 社会保険未加入
- **内容**: `M1|P005|田中四郎|田中建設||0||48|0`
- **説明**: 複数の警告が発生するケース
- **特徴**:
  - CCUS未登録（空文字）
  - 社会保険未加入 (0)
  - 複数の警告メッセージが表示される

## 使用方法

1. MC-Gate モバイルアプリを起動
2. スキャン画面でカメラを起動
3. 任意のQRコードを読み取る
4. ルール判定結果を確認

## テストシナリオ

### 正常系
- P001（完全データ）を読み取り → すべてグリーン、警告なし

### 警告系
- P002（CCUS未登録）を読み取り → CCUS未登録の警告
- P003（外国人労働者）を読み取り → 在留期限チェック
- P005（複数問題）を読み取り → 複数の警告

### 特殊ケース
- P004（一人親方）を読み取り → 社会保険未加入でも警告なし

## 生成スクリプト

QRコードを再生成する場合:

```bash
# mc-gateディレクトリから実行
bash scripts/generate-qr-simple.sh
```

または

```bash
# qrcodeパッケージをインストールしている場合
node scripts/generate-qr.js
```

## 注意事項

- これらのQRコードはテスト用です
- 本番環境では実際のworkerデータを使用してください
- QRコード画像は300x300ピクセル、エラー訂正レベルMで生成されています
